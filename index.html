NHID-Clinical is an open governance framework for healthcare voice agents that helps organizations verify identity, enforce disclosure, and create auditable AI interactions before sensitive workflows begin.

This site is an interactive simulator that demonstrates the NHID-Clinical framework — a governance model of controls and requirements. The simulator is education and demonstration; it is not the framework itself.
